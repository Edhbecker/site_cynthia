# Portfólio — Cynthia Aparecida da Silva

Landing page institucional e portfólio estático para Cynthia Aparecida da Silva.

## Tecnologias

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Lucide React

O projeto não utiliza banco de dados, backend, autenticação ou API para exibir conteúdo. Textos, projetos, serviços e informações profissionais ficam em `client/src/data/site-content.ts`; as imagens ficam em `client/public/images`.

## Executar localmente

```bash
npm install
npm run dev
```

## Verificações

```bash
npm run check
npm run build
```

O build estático é gerado em `dist/` e pode ser publicado em qualquer hospedagem de arquivos estáticos.
